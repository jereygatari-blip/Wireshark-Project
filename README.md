# Wireshark-Project
# Malicious Traffic Detection & Packet Analysis Lab

## Overview

Analyzed network traffic in Wireshark to examine DNS, ARP, and HTTP activity and look for potential security issues.

## Tools Used

- Wireshark
- Packet Capture Analysis
- DNS Analysis
- ARP Analysis

## Methodology

Captured and filtered network packets in Wireshark to examine:
- DNS requests and responses
- ARP requests and replies
- Network communication between devices
- Potential unusual traffic

## Key Findings

### DNS Traffic

- Analyzed DNS requests and responses from devices on the network
- Identified traffic from services including Grammarly, Google, Anthropic, and Joinhoney
- Examined IPv4 and IPv6 DNS responses

### ARP Traffic

- Analyzed ARP requests and replies between devices
- Observed repeated gratuitous ARP traffic from Ring devices
- Examined how devices communicate across the local network

### HTTP Analysis

- Used the `http` filter to check for HTTP traffic
- No HTTP packets appeared in the captured traffic

- Network security analysis

This lab gave me hands-on experience analyzing network traffic and using Wireshark to investigate device communication and potential security issues.
